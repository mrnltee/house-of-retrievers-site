## 6. Gotchas worth knowing

- **Declaration order in `JoinModal.jsx`.** `withFurbabies` must come after
  `asksAboutFurbaby`. Reordering them crashes the form ("Cannot access … before
  initialization").
- **No nested forms.** The editor's RSVP form preview is a real form. That's
  why the Preview dialog is a portal.
- **Argument order.** `openTiers(tiers, counts)` takes two arguments. An older
  call passed `Date.now()` in between; there is a test for it now.
- **Public tickets.** `toPublicEvent` tickets must carry `limitUnit` and
  `withPrevious`, or the RSVP says "registrants" instead of "furbabies".
- **Shared fit check.** Late proof, reminders and admin Approve all use
  `expiredHoldFits` (`app/lib/expiredHoldFit.js`), which checks capacity, the
  ticket's first-N and the public hooman limit. Don't add a second version.
- **Breed icons.** Don't run `scripts/breed-icons/build.mjs`; it overwrites
  HOR's icons. Use `import.mjs`.
- **Spam guard in tests.** A submission faster than the minimum fill time gets
  a *fake* success. Wait before submitting in browser tests.
- **Signing in.** When the admin session expires during a browser check, ask the
  owner to sign in again. Never sign in for them.
- **Emails are live** in production. Test locally with the email env vars blank
  (AGENTS.md §8).
